# BoxKita V23 — Catatan Rilis

- Menu utama desktop dan mobile kini berisi: **Menu**, **Promosi Mitra**, **Cara Pesan**, **Mitra Kuliner**, dan **Jadi Mitra**.
- Jumat Barokah dan BoxKita Aneka Kue tetap ada sebagai bagian halaman dan kategori katalog, tetapi tidak lagi memenuhi navigasi utama.
- Tipografi utama, navigasi, menu kategori, formulir, footer dan dashboard diperbesar untuk keterbacaan lebih baik.
- Pada HP yang sangat kecil, produk ditampilkan satu kolom agar nama dan deskripsi tidak sesak.
- CSS, JS, manifest dan cache PWA dinaikkan ke V23.

Publikasikan dengan mengunggah semua berkas ke root GitHub Pages. Untuk menguji PWA versi baru, tutup aplikasi sepenuhnya dan buka kembali situs melalui browser.
