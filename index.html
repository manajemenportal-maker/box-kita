AREA TERBATAS

Login pengelola

Gunakan akun pengelola yang terdaftar di Firebase Authentication.

Akun baru hanya memperoleh akses dashboard setelah UID-nya diberi role admin oleh pemilik project Firebase.

PENDAFTARAN PERTAMA

Buat akun login pengelola

Akun dibuat di Firebase Authentication. Untuk keamanan, hak akses administrator tetap harus diaktifkan di Firestore.

Akun berhasil dibuat

—
Aktifkan hak pengelola satu kali di Firebase Console
  1. Buka Firestore Database → Data pada project box-kita.
  2. Buat collection users (bila belum ada), lalu buat dokumen dengan Document ID persis UID di atas.
  3. Tambahkan field role bertipe string dengan nilai admin.
  4. Tambahkan field active bertipe boolean dengan nilai true.
  5. Setelah disimpan, kembali ke sini dan login dengan email/password yang baru dibuat.

Langkah ini manual agar pengunjung umum tidak dapat memberikan hak administrator kepada dirinya sendiri.
